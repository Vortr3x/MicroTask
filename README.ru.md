# MicroTask

Приложение для записи и воспроизведения макросов для Linux с поддержкой Wayland и X11.

[English](README.md) | [Русский](README.ru.md)

MicroTask записывает события мыши и клавиатуры напрямую из интерфейсов ядра Linux (`/dev/input/event*`) и воспроизводит их через виртуальное устройство (`/dev/uinput`). Это позволяет обходить ограничения изоляции оконных менеджеров Wayland (KDE Plasma, GNOME, Sway, Hyprland), сохраняя полную совместимость с X11.

## Возможности

- Запись ввода: относительные перемещения мыши, колесо прокрутки, клики (левая, правая, средняя, дополнительные кнопки) и нажатия клавиш клавиатуры.
- Синхронизация курсора в Wayland: фиксация стартовой позиции курсора перед началом записи и воспроизведения для точного попадания по элементам интерфейса.
- Управление воспроизведением: настройка скорости (от 0.25x до 10.0x), количества повторений, бесконечный цикл и паузы между итерациями.
- Глобальные горячие клавиши: фоновый перехват горячих клавиш независимо от фокуса окна или полноэкранных приложений.
- Аварийная остановка: кнопка экстренного прерывания, мгновенно останавливающая воспроизведение и отпускающая все зажатые клавиши и кнопки.
- Редактор макросов: просмотр таймлайна событий, значений смещений и задержек, удаление лишних событий и нормализация таймингов.
- Сохранение настроек: параметры воспроизведения, синхронизации курсора и фильтры устройств автоматически сохраняются в `~/.config/microtask/settings.json`.
- Формат JSON: макросы сохраняются в понятном текстовом формате JSON.

## Горячие клавиши по умолчанию

| Клавиша | Действие |
| --- | --- |
| `F9` | Начать / остановить запись |
| `F10` | Воспроизведение / пауза / продолжить |
| `Pause` или `F12` | Аварийная остановка (сброс всех зажатых клавиш и остановка) |

## Права доступа и настройка

MicroTask взаимодействует напрямую с подсистемой ввода ядра Linux. Пользователь должен иметь права на чтение `/dev/input/event*` и запись в `/dev/uinput`.

### 1. Добавление пользователя в группу `input`

```bash
sudo usermod -aG input $USER
```

### 2. Настройка правила udev для `/dev/uinput`

Если в вашем дистрибутиве `/dev/uinput` недоступен для группы `input`, создайте файл `/etc/udev/rules.d/99-uinput.rules`:

```bash
echo 'KERNEL=="uinput", MODE="0660", GROUP="input", OPTIONS+="static_node=uinput"' | sudo tee /etc/udev/rules.d/99-uinput.rules
```

Примените правила udev:

```bash
sudo udevadm control --reload-rules && sudo udevadm trigger
```

После этого перезайдите в сеанс пользователя, чтобы изменения групп вступили в силу.

## Сборка и запуск

### Требования

- Rust (stable, версия 2021 или новее)
- Ядро Linux с поддержкой `/dev/uinput`

### Сборка для разработки

```bash
cargo run
```

### Сборка релизной версии

```bash
cargo build --release
./target/release/microtask
```

### Параметры командной строки

```bash
# Проверка прав доступа и доступности устройств ядра
./target/release/microtask --diagnostics

# Список всех обнаруженных клавиатур и мышей
./target/release/microtask --list-devices

# Справка по флагам запуска
./target/release/microtask --help
```

## Конфигурация

Настройки автоматически сохраняются в `~/.config/microtask/settings.json`. В файле сохраняются:
- Скорость воспроизведения, количество циклов и задержка между ними
- Режим привязки курсора (Center, Top-Left, Custom) и координаты
- Движок позиционирования курсора
- Коды глобальных горячих клавиш
- Фильтры включенных и отключенных устройств ввода

Настройки также можно вручную сохранить или сбросить до значений по умолчанию на вкладке Settings в интерфейсе.
